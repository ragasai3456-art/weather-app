# Weather App 🌤️

A simple weather forecast web application built using HTML, CSS, and JavaScript.  
It fetches real-time weather data using the OpenWeather API and displays temperature, weather conditions, humidity, and wind speed.

## 🚀 Live Demo
https://ragasai3456-art.github.io/weather-app/

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- OpenWeather API

## 📌 Features
- Search weather by city
- Real-time weather updates
- Clean and responsive UI
- Hosted using GitHub Pages
